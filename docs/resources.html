COMMON QUESTIONS

Find your answer.

Can I create an account before choosing a paid plan?+

Yes. You can create a Qanteak account and download the Windows app. Paid feature access depends on an active subscription. Creating an account does not charge you.

How does annual pricing work?+

Basic is $180 per year, Pro is $288 per year, and Teams is $384 per seat per year. The displayed monthly equivalent is billed as a yearly total once checkout is available.

Is Qanteak a browser app or desktop app?+

Qanteak is currently available as a Windows desktop release. This website lets you explore the product, create an account and download the app. macOS and mobile downloads are not available yet.

Does the price include unlimited AI?+

No unlimited hosted AI allowance is promised here. Model-backed reasoning, transcription and live external integrations depend on configured services and their availability.

Can I bring my existing work?+

The workspace platform includes CSV, JSON and Markdown import and export foundations. Start with a small sample and review the mapping before importing a full dataset.

How does Qanteak approach AI permissions?+

The architecture uses context scopes, tool allow-lists, proposed plans, approval gates and audit history. Read the security page for more detail.
