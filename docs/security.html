Security

Last updated: September 4, 2026

Qanteak OS is a desktop-first workspace that combines local Windows functionality with optional cloud services. Security work focuses on minimizing unnecessary access, keeping account data separated between users, and preserving a clear boundary between local files and cloud-connected features.

Account and cloud access

Qanteak uses authenticated account sessions for cloud-connected features. The production backend uses row-level access policies so authenticated users can access only records associated with their account. Subscription entitlements are also associated with the authenticated account.

Local files

The desktop application accesses files and folders through explicit user actions or locations the user has chosen to index. Qanteak does not require all local creative files to be uploaded to the cloud in order to organize them.

Payments

Payment card data is intended to be processed by the configured merchant-of-record/payment platform rather than stored directly by Qanteak OS. Qanteak receives only the order and subscription metadata needed to determine software access.

Updates and recovery

Qanteak supports signed metadata checks for application updates and maintains local backup/recovery tooling for workspace data. Users should still keep independent backups of important creative source files.

Vulnerability reporting

If you believe you have found a security issue in Qanteak OS or its website, please report it privately to hamza.workjo@gmail.com. Include the affected component, steps to reproduce, expected impact and any screenshots or logs that help explain the issue. Please avoid accessing or modifying data that does not belong to you.

Pre-release status

Release-candidate builds may change before general availability. Security findings discovered during the private beta are prioritized before public release.
