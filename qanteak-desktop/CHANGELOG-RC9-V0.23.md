# Qanteak OS RC9 V0.23

A new warm-white workspace with charcoal navigation, pastel task boards, and a corporate finance overview.

- Dedicated Tasks page with project/search filters and drag or keyboard-accessible status selection.
- Client map connects existing clients, projects, tasks, documents, files, invoices and reviews. Drag nodes, pan, zoom, filter, open linked records and save a personal cloud layout.
- Private coworker conversations and named groups with selected participants, unread counts, persisted drafts during navigation, retry-safe sending and older-message loading. Refreshes every five seconds while the app is running.
- Personal reminders with sound, desktop notification, snooze and missed-reminder recovery while the app is open. Fully closed applications cannot deliver alarms.
- Home check-in/check-out, today's elapsed work time, personal shift history and owner/admin team attendance. Times are recorded by the server; one open shift per person per workspace.
- Finance overview uses existing invoices and expenses, with collection ratio, expense categories and CSV export. No simulated bank cards or bank transfers.
- New collaboration tables are separate from legacy snapshot storage and accessible only through membership-checked server functions. Private chats are restricted to their selected participants.

Existing workspace data and desktop update identity are preserved. Studio's universal databases remain local-only. Windows signing still depends on a configured signing certificate; the release pipeline reports signature status. A physical installed-device update and OS notification behavior require Windows verification.
