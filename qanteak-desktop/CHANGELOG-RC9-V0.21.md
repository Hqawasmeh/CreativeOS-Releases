# Qanteak OS RC9 V0.21

Workspace foundation development update.

## Added
- Project and client comments with @mention notifications.
- Entity activity history foundation.
- Project/client custom fields.
- Rich document formatting toolbar.
- Expanded universal search across tasks, reviews, estimates, expenses and comments.
- Project saved views and reusable status filters.
- File version grouping.
- Project profitability summary using deterministic invoice and expense totals.
- Expanded project/client detail navigation tying documents, reviews, finance and collaboration together.

## Notes
- This development update builds on the V0.20 AI branch and remains isolated from the public RC9 release until QA is complete.
- Comments/activity/saved views are included in the shared workspace snapshot model.
