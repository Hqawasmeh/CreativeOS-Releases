# Qanteak OS RC9 V0.16

Scoped document, lifecycle and permissions update.

- Added a real spreadsheet-style Sheet editor with cells, row/column headers, formula bar and basic formulas.
- Removed Slides from document creation while keeping Documents, Notes and Sheets.
- Kept the sidebar Qanteak logo white in both light and dark appearance modes.
- Added phone number support to client creation.
- Added permission-aware Archive and Delete actions to opened projects, tasks, reviews, clients, files, documents/sheets and invoices.
- Archived items are hidden from active views and can be restored from Settings.
- Added open/detail actions for tasks, reviews and files so lifecycle controls are consistently available.
- Redesigned the invite/member custom-access matrix with aligned module/action columns and clearer controls.

Tag: `v1.0.0-rc.9.16`
