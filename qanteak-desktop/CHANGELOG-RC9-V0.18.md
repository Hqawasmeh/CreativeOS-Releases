# Qanteak OS RC9 V0.18

Workspace recovery + New button hotfix.

- Keeps the V0.17 cloud-hydration safeguards that protect existing workspace data during startup/network failures.
- Changes the top-right New button from Search to a dedicated Create New popup.
- The popup includes Project, Task, Review, Client, Lead, Document, Note, Sheet, Invoice, Expense, Automation and Upload File.
- Creation choices are filtered by the current member’s create permissions.
- Slides remain removed.
